MindLog プライバシーポリシー

ホーム プライバシーポリシー 利用規約

最終更新日: 2026年8月2日

MindLog（以下「本アプリ」）は、個人開発スタジオ Nemurineko Studio（連絡先: checkup850@gmail.com、以下「開発者」）が提供するAI日記アプリです。 本ポリシーは、本アプリが取り扱う情報とその利用目的を説明するものです。

1. 取得する情報

ユーザーが入力する情報

  • 日記の本文・気分タグ・写真: 本アプリの中核機能である日記の記録のために取得します
  • アカウント情報（メールアドレス）: アカウントの識別のために取得します

自動的に取得される情報

  • 購入情報: サブスクリプションの購入状態を管理するため、決済基盤（RevenueCat / App Store / Google Play）を通じて取得します。クレジットカード番号等の決済情報を開発者が直接取得することはありません

2. 情報の保存場所

  • 日記データ（本文・気分タグ・写真）は、機能提供のためGoogle Firebase（Google Cloud Platform）に保存されます
  • 端末がオフラインの間は端末内に一時保存され、接続時に同期されます

3. AI機能における情報の取り扱い

AIフィードバック・週次/月次/年間レポート等のAI機能を利用する場合、対象となる日記テキストがAnthropic社のClaude APIに送信されます。

  • 送信されるのは、機能の実行に必要な日記テキストと気分タグのみです
  • Anthropic社のAPIは、送信されたデータをモデルの学習に使用しません（Anthropic社の商用API利用規約に基づく）
  • AI機能を利用しない場合、日記データが外部のAIサービスに送信されることはありません

4. 利用目的

  1. 日記の記録・表示・同期などの本アプリの機能提供
  2. AIフィードバック・レポート等のAI機能の提供
  3. サブスクリプションの購入状態の管理
  4. お問い合わせへの対応

5. 第三者提供

法令に基づく場合を除き、ユーザーの同意なく個人情報を第三者に提供することはありません。 前述のFirebase（Google）、Claude API（Anthropic）、RevenueCatは、機能提供に必要な範囲での処理の委託先です。

6. データの削除

  • アプリ内の「設定 → アカウントを削除」から、アカウントと日記データ（写真を含む）をすべて削除できます
  • 削除のご依頼は下記メールアドレスでも受け付けます。本人確認のうえ、登録データを削除します

7. 通知

リマインダー通知は、ユーザーが設定した場合にのみ、端末のローカル通知として送信されます。通知のために外部にデータが送信されることはありません。

8. 生体認証

アプリロック機能で使用する生体認証（Face ID / 指紋認証）は端末のOS機能を利用するものであり、生体情報が本アプリや開発者に送信されることはありません。

9. 未成年の利用

本アプリは、保護者の同意のもとでご利用ください。

10. ポリシーの変更

本ポリシーを変更する場合は、アプリ内または本ページでお知らせします。
